# Minecraft

Minecraft es un popular juego sandbox de construcción y supervivencia.

## Instalación

Para instalar el Launcher de Minecraft, ejecuta el siguiente comando:

`yay -S minecraft-launcher`

## Documentación

Para obtener más información, visita la página oficial de [Minecraft](https://www.minecraft.net/) y el paquete en [AUR](https://aur.archlinux.org/packages/minecraft-launcher).
