# Zed

Zed es un editor de código muy rápido y moderno.

1. Instalar

   Para instalar Zed, utiliza el siguiente comando en la terminal.

   `sudo pacman -S zed`

---

2. Configuración

   Para revisar mi configuración personal, consulta el archivo: [Zed-config](zed-config.md)

## Documentación

Para mayor información se recomienda visitar la pagina oficial de [Zed](https://zed.dev/)
