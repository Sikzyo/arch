# Android Studio

Android Studio es el entorno de desarrollo integrado (IDE) oficial para el desarrollo de aplicaciones Android. Proporciona herramientas avanzadas para diseñar, desarrollar, depurar y empaquetar aplicaciones Android.

1. Instalación

Para instalar Android Studio en Arch Linux, utiliza el siguiente comando:

`yay -S android-studio`
