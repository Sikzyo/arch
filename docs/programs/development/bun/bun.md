# Bun

Bun es un runtime de JavaScript muy rápido que sirve para ejecutar, instalar y probar proyectos JS/TS todo en uno.

1. Instalar

   Para instalar Bun, utiliza el siguiente comando en la terminal.

   `sudo pacman -S bun`

## Documentación

Para mayor información se recomienda visitar la pagina oficial de [Bun](https://bun.com/)
