# Nodejs

Node.js es un entorno de ejecución de JavaScript que permite crear aplicaciones y servidores rápidos fuera del navegador.

1. Instalar

   Para instalar Nodejs, utiliza el siguiente comando en la terminal.

   `sudo pacman -S nodejs`

## Documentación

Para mayor información se recomienda visitar la pagina oficial de [Nodejs](https://nodejs.org) y la documentación de Arch Linux en [Nodejs Arch](https://wiki.archlinux.org/title/Node.js)
