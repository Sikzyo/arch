# Nvtop

Monitor de procesos GPU para NVIDIA que muestra el uso de la GPU, memoria de video y procesos en tiempo real.

1. Instalación

   Para instalar Nvtop, ejecuta el siguiente comando en la terminal.

   `sudo pacman -S nvtop`

## Documentación

Para obtener más información, se recomienda visitar la página oficial de [Nvtop](https://github.com/Syllo/nvtop)
