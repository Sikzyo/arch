# Cava

Cava es un visualizador de audio para la terminal de Linux.

## 1. Instalación

Para instalar Cava, ejecuta el siguiente comando en la terminal:

```bash
sudo pacman -S cava
```

## Documentación

Para obtener más información, se recomienda visitar el repositorio oficial de [cava](https://github.com/karlstav/cava?tab=readme-ov-file#configuration)
