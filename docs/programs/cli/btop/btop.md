# Btop

Monitor de recursos del sistema interactivo que muestra CPU, memoria, discos y red en tiempo real.

## 1. Instalación

Para instalar Btop, ejecuta el siguiente comando en la terminal:

```bash
sudo pacman -S btop
```

## Documentación

Para obtener más información, se recomienda visitar la página oficial de [Btop](https://github.com/aristocratos/btop)
