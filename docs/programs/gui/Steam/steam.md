# Steam

Steam es una plataforma para comprar, descargar y jugar videojuegos en PC

1. Instalación

   Para instalar Steam, ejecuta el siguiente comando en la terminal:

   `sudo pacman -S steam`

## Documentación

Para obtener más información, se recomienda visitar la página oficial de [Steam](https://store.steampowered.com/) y la documentación de Arch Linux de [Steam Arch](https://wiki.archlinux.org/title/Steam)
