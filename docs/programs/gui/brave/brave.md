# Brave

Brave es un navegador web rápido y enfocado en la privacidad del usuario.

1. Instalación

   Para instalar Brave, utiliza el siguiente comando en la terminal.

   `curl -fsS https://dl.brave.com/install.sh | sh`

2. Configuración

   Para revisar mi configuración personal, consulta el archivo: [Brave-config](brave-config.md)

## Documentación

Para mayor información se recomienda visitar la pagina oficial de [Brave](https://brave.com/)
