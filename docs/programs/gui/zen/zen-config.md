# Zen config

1. Desactivar hover de la barra lateral

   Para desactivar el hover de la barra y hacer que únicamente se muestre mediante comandos de teclado, sigue estos pasos:
   - En el buscador escribe:
     - `about:config`
   - Una vez dentro, busca:
     - zen.view.compact.show-sidebar-and-toolbar-on-hover
   - Cambia el valor de `on` a `off`
