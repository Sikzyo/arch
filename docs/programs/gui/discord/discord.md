# Discord

Discord es una plataforma de comunicación que permite chatear mediante texto, voz y video.

1. Instalación

   Para instalar Discord, ejecuta el siguiente comando en la terminal.

   `sudo pacman -S discord`

## Documentación

Para obtener más información, se recomienda visitar la página oficial de [Discord](https://discord.com/) y la documentación de Arch Linux en [Discord Arch](https://wiki.archlinux.org/title/Discord)
