# Spotify

Spotify es una plataforma de música y podcasts en streaming que te permite escuchar, descubrir y crear playlists.

1. Instalación

   Para instalar Spotify, ejecuta el siguiente comando en la terminal:

   `sudo pacman -S spotify-launcher`

## Documentación

Para obtener más información, se recomienda visitar la página oficial de [Spotify](https://open.spotify.com/) y la documentación de Arch Linux en [Spotify Arch](https://wiki.archlinux.org/title/Spotify)
