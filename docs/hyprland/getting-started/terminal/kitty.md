# Kitty

Kitty es un emulador de terminal rápido y moderno, con aceleración por GPU

1. Instalación

   Para `kitty` ejecuta el siguiente comando:

   `sudo pacman -S kitty`

---

2. Configuración

   Para abrir la configuración de `kitty` utiliza:

   `ctrl+shift+f2`

   El archivo de configuración se encuentra ubicado en:

   `~/.config/kitty/kitty.conf`

## Documentación

Para obtener más información, se recomienda visitar la página oficial de [Kitty](https://sw.kovidgoyal.net/kitty/)
