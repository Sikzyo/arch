# Kitty

Kitty es un emulador de terminal rápido y moderno, con aceleración por GPU

## 1. Instalación

Para `kitty` ejecuta el siguiente comando:

```bash
sudo pacman -S kitty
```

## 2. Configuración

Para abrir la configuración de `kitty` utiliza:

`ctrl+shift+f2`

El archivo de configuración se encuentra ubicado en:

`~/.config/kitty/kitty.conf`

## 3. zsh

Se recomienda instalar `zsh`. Para más información, consulta el archivo [zsh](zsh.md)

## 4. Mi configuración

Puedes consultar mi configuración personal de `kitty` en el siguiente archivo:

[kitty.conf](/config/kitty/kitty.conf)
