# zsh

Zsh es un shell interactivo moderno con muchas mejoras sobre bash.

## 1. Instalación

Para instalar `zsh` ejecuta el siguiente comando:

```bash
sudo pacman -S zsh
```

## 2. Configuración

Para establecer `zsh` como tu shell predeterminada, ejecuta:

```bash
chsh -s /usr/bin/zsh
```

Después de ejecutar este comando, cierra sesión y vuelve a entrar para que los cambios surtan efecto.
